Technical SEO Audit Checklist: 24 Checks That Actually Matter

A prioritized technical SEO audit checklist covering crawlability, indexation, sitemaps, canonicals, redirects, Core Web Vitals and structured data — in the order to fix them.

How to use this checklist

Run these checks in order: crawlability first (if Google cannot reach a page, nothing else matters), then indexation, then on-page technical signals, then performance. Grade every finding by impact and effort so fixes ship in the right sequence.

Crawlability checks

Confirm search engines can reach everything that matters:

  • robots.txt allows important sections and blocks nothing critical by accident
  • XML sitemap exists, is current, and lists only canonical, indexable URLs
  • No important page is more than 3–4 clicks from the homepage
  • Orphan pages (no internal links) are found and linked or removed
  • Crawl budget is not wasted on faceted, parameter or infinite-space URLs
  • Server returns correct status codes — no soft 404s

Indexation checks

Verify the right pages are indexed — and only those:

  • Site: and Search Console coverage match your intended indexable set
  • Canonical tags point to the preferred version on every duplicate set
  • noindex is used deliberately, never left over from staging
  • Redirect chains are flattened; loops eliminated
  • Hreflang (if used) is reciprocal and returns valid targets
  • Duplicate title/meta patterns are resolved at template level

Performance and page experience

Core Web Vitals are a ranking input and a conversion input:

  • LCP under 2.5s on key templates (mobile)
  • INP under 200ms — check heavy scripts and long tasks
  • CLS under 0.1 — reserve space for images, fonts and embeds
  • Images are compressed, correctly sized and lazy-loaded below the fold

Structured data and final checks

Validate structured data against eligibility rules — only mark up content that exists on the page and qualifies for the schema type. Finish with HTTPS consistency, mobile rendering checks, and a log-file spot check if available.
